# PayProof: Autonomous Gig-Worker Audit Agent
*Founder's Code 2026 - Tech & Business Track*

## Architecture Overview
PayProof is a deterministic AI auditing agent that turns opaque gig payouts into cryptographically verifiable grievance evidence.
- **Frontend:** Next.js / Tailwind CSS
- **Execution Engine:** Python (FastAPI)
- **Ingestion:** Tesseract OCR / Firecrawl API
- **Audit Logging:** SQLite WAL with RFC 8785 Hash Chaining
